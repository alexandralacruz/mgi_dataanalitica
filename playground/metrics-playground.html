Tensors y and ŷ

A regression metric is a distance between two tensors: the actual y and the prediction ŷ. Drag the top of any bar to change its component value.

yᵢ (actual) ŷᵢ (predicted) residual rᵢ = yᵢ − ŷᵢ

2D geometry of distance

Using components i = 0 and i = 1, the tensors become two points on a plane. Each distance function draws a different path between them.

y ŷ L¹ staircase (Manhattan) L² line (Euclidean) L∞ max (Chebyshev)
