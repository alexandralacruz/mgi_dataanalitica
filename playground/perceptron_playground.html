Weighted Sum

z = w₁·x₁ + w₂·x₂ + b

Each input is multiplied by its weight. The bias shifts the decision boundary independently of the inputs.

Activation (Step)

ŷ = 1 if z ≥ 0, else 0

The step function converts the continuous weighted sum into a binary class prediction.

Weight Update Rule

wᵢ ← wᵢ + η · (y − ŷ) · xᵢ

If the prediction is wrong, nudge the weights in the direction that would have produced the correct answer.
