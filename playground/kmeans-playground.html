// THE CONCEPT

K-Means Clustering partitions data into K groups by finding K centroids that minimize the total distance from each point to its nearest centroid.

J = Σk=1K Σx∈Ck ||x - ck||²
  • K = number of clusters (chosen in advance)
  • ck = centroid (mean) of cluster k
  • J = inertia (total within-cluster variance)
  • Goal: minimize J by iterating assign → update
// ANALOGY: PIZZA DELIVERY

Imagine placing K pizza shops in a city so that every house is as close as possible to a shop. K-Means finds the best locations for those shops — the centroids — by repeatedly adjusting them until each shop sits at the center of its delivery zone.

// WHY K MATTERS

Choosing the right K is crucial. Too few clusters = poor fit. Too many = overfitting. The Elbow Method plots inertia vs K. Look for the "elbow" where adding more clusters stops helping much.

  • K=1: everything in one group (high inertia)
  • K=N: each point is its own cluster (zero inertia, useless)
  • Sweet spot: the bend in the elbow curve

// INITIALIZATION MATTERS

K-Means converges to a local optimum, not necessarily the global best. Different random starting positions for centroids can lead to very different clusters!

  • Bad init = centroids stuck in wrong positions
  • Solution: run multiple times, pick best inertia
  • K-Means++: smarter initialization (spread centroids apart)
// ANALOGY: HIKING

K-Means is like walking downhill to find the lowest valley. Where you start determines which valley you end up in. Starting from different peaks might lead to different valleys — some deeper than others.

// K-MEANS ALGORITHM - STEP BY STEP

01
Choose K and initialize centroids
c_1, c_2, ..., c_K = random points from data
02
Assign each point to nearest centroid
label_i = argmin_k ||x_i - c_k||^2
03
Update centroids to cluster means
c_k = (1/|C_k|) * sum(x_i for x_i in C_k)
04
Check convergence
if centroids unchanged: stop, else: goto step 02
