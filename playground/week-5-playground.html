What is an SVM?

A Support Vector Machine is a supervised algorithm that finds the optimal hyperplane separating classes with the largest possible margin.

Hyperplane & Margin

The decision boundary is defined by:

w · x + b = 0

The margin is the distance between the boundary and the closest points from each class. SVM maximizes this margin for better generalization.

Support Vectors

  • The data points that sit exactly on the margin boundary
  • They alone define the hyperplane — remove other points and nothing changes
  • This makes SVMs memory-efficient: only critical points matter

Hard vs Soft Margin

Hard margin: Perfect separation required. Fails on noisy or overlapping data.
Soft margin: Allows misclassifications controlled by the C parameter.
High C = strict (risk overfitting)  |  Low C = flexible (risk underfitting)

The Kernel Trick

When data isn't linearly separable, a kernel function K(x, x') measures similarity and implicitly maps data to higher dimensions where linear separation becomes possible.

Common Kernels

  • Linear: K(x, x') = x · x' — for linearly separable data
  • Polynomial: K(x, x') = (x · x' + c)d — captures feature interactions
  • RBF (Gaussian): K(x, x') = exp(-γ ||x - x'||²) — flexible, default choice
Tip: Start simple (linear), increase complexity only if needed. Always scale features before training. Use cross-validation to tune C, γ, and degree.

Hyperplane & Decision Boundary

A hyperplane is the boundary that separates classes. In 2D it's a line defined by w · x + b = 0. Drag the sliders to control the line's orientation and position, and see how it classifies each region.

Decision boundary explorer

Hyperplane equation

w₁·x₁ + w₂·x₂ + b = 0
w = normal vector (perpendicular to the line). It points toward the positive class region.
b = bias. Shifts the line away from the origin.
Points where w·x + b > 0 are Class +, otherwise Class −.

The Kernel Trick

Data that can't be separated by a line in 2D can often be separated in a higher-dimensional space. The kernel trick does this implicitly. Watch the transformation live.

TRANSFORM
Transformed feature space
After mapping φ(x) = (x₁, x₂, x₁² + x₂²), a flat plane can separate the classes!
Key insight: The kernel function K(x, x') = φ(x) · φ(x') computes the dot product in the transformed space without ever explicitly computing φ. This is the "trick" — we get the power of high-dimensional separation at the cost of a simple function evaluation.
